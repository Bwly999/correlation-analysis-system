## 这个系统能帮你做什么

如果你手里有一份生产/质量数据，想知道：

- 哪些工艺因子和最终良率/缺陷**最相关**？
- 几十个候选变量里，哪些**最值得优先关注**？
- 一个结果波动，到底是**哪些变量**在推动？
- 不同批次/方案之间，关键指标**差在哪**？

本系统提供两种工作方式来完成上述任务：

| 方式 | 适合谁 | 特点 |
|------|--------|------|
| **工作流编辑器**（主入口） | 想自己掌控分析流程的人 | 拖拽节点搭流程，每一步可见、可调、可复用 |
| **AI 分析**（笔记本） | 想快速出洞察、不想自己搭流程的人 | 给数据和目标，AI 用 Python 自由分析，产出图文报告 |

两套入口**各管一摊**：工作流管"流程"，AI 分析管"洞察"。
