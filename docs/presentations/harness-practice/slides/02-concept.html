// 1. 什么是 HARNESS ENGINEERING

马具与操作系统：模型能力并非瓶颈

"Harness"本意是马具（缰绳与鞍具）。LLM 就像蛮力十足但方向感弱的野马，Harness Engineering 则是约束、反馈与可测量的控制体系。

业界实验（Can.ac 与 LangChain）验证了核心论断：瓶颈在于基础设施，而非智能水平。在纠结模型权重前，优化 Harness 往往能带来数倍的投资回报率。

Can.ac 实验: 工具格式改动引发质变
在完全不修改模型权重的前提下，仅将 Harness 暴露的编辑工具格式与返回形式做标准化优化，同一模型（Grok Code Fast 1）的基准分数便从 6.7% 提升至 68.3%。

LangChain 实验: 终端基准跃升
在 Terminal Bench 2.0 评测中，仅通过改进 Agent Harness 的运行与约束机制，在模型未变的前提下得分拉升 13.7 分，排名从第 30 名跃升至第 5 名。
