受控工具、活文档与可观测性集成

Agent 具备编写与运行代码的强大工具，但绝不能失去边界。我们通过将文档活化、代码硬限与环境感知可观测化，建立坚不可摧的物理防御阻尼层。

AGENTS.md 作为活的反馈回路 (Hashimoto 模式)
AGENTS.md 严禁作为静态文档遗忘。每次 Agent 犯错，均被沉淀为该文档中的一行硬约束。这意味着，大模型发生的每一例异常，均通过更新活文档沉淀为 Harness 层的硬约束规则。
请求接口的机械化强硬防御 (Axios HttpClient Guard)
前端严禁使用裸 fetch 或自主拼接 API URL。所有接口请求必须收口至 src/services/httpClient.ts。一旦违反，自定义 Linter 会在提价阶段直接阻断，实现机械化方向性约束。
浏览器可观测性集成 (Chrome DevTools MCP)
集成 chrome-devtools-plugin，Agent 具备直接调用 Puppeteer 抓取 canvas 渲染 DOM 树与截图的能力，可直接感知 Vue Flow 节点的渲染位置。
技术债的“垃圾回收”机制 (Entropy GC)
AI 生成代码的“熵增”积累方式异于人类。项目定期运行清理 Agent，对项目文档不一致、冗余导入或低质代码段执行“垃圾回收”（GC），确保系统清洁。
