核心统计分析节点 / STATISTICAL TERMINALS
单调性相关分析
分析因子与目标值的线性或单调关系。最基础的因子筛选手段。
Pearson / Spearman / Kendall
VIF 共线性检测
在建模前检测解释变量之间是否存在高度相关，防止模型失真。
Variance Inflation Factor
PCA 主成分分析
对高维因子进行降维，识别能够解释大部分方差的核心主成分。
Principal Component Analysis
ANOVA 方差分析
比较不同分组（如不同班次、不同供应商）之间的均值是否存在显著差异。
Analysis of Variance
分类因子筛查
当目标 Y 是分类变量时，筛选哪些因子对分类结果有显著影响。
Chi-Square / T-Test / Kruskal
💡 建议：在进入机器学习建模前，优先使用 VIF 检测共线性，并使用 PCA 或 相关分析精简变量。
