01 核心概念 Core Concepts

02 / 08
01 起点
TRIGGER
触发节点

流程的入口，没有输入只有输出。
负责将原始数据或运行时参数引入工作流。

  • 本地文件导入 (CSV/Excel)
  • 手动 JSON 录入
  • 外部系统数据对接 (Neighbor)
02 中转
ACTION
处理节点

流程的中段，有输入也有输出。
负责数据清洗、字段映射、多表关联、聚合等。

  • 异常值/缺失值处理
  • 数据筛选与排序
  • 多源数据合并 (横向/纵向)
03 终点
TERMINAL
终点节点

流程的归宿，只有输入没有输出。
执行核心算法、生成报告、绘图或导出结果。

  • 相关性分析/回归建模
  • SHAP 重要性解释
  • 图表展示与文件导出
Data Flow: Trigger ➔ Action ➔ Terminal
