高级算法与回归建模 / MACHINE LEARNING TERMINALS

XGBoost + SHAP

系统最核心的白盒化分析工具。不仅能捕捉非线性关系，还能通过 SHAP 解释每一个因子的贡献度。

  • 自动识别非线性影响趋势
  • 输出直观的因子依赖图 (Dependence Plot)
  • 适用于大部分工业连续数值场景

随机森林特征重要性

适合面对成百上千个变量时，快速筛选出对结果影响最大的 Top 特征组合。

  • 对异常值不敏感
  • 自动处理特征间的高阶交互

多元线性回归

经典的回归模型，输出明确的数学公式，量化解释各因子的影响权重。

  • 极高的可解释性与公式化输出
  • 适合符合线性分布的基础工艺场景

Lasso 回归

带正则化的回归，会自动将不重要的因子权重压缩为 0，实现特征自动精简。

  • 自动变量选择功能
  • 防止模型过拟合，提高泛化能力

逻辑回归分类分析

当目标 Y 是离散标签（如 良品/不良品）时，使用此节点分析因子的分类贡献。

  • 输出混淆矩阵与 ROC 曲线
  • 支持二分类与多分类场景
