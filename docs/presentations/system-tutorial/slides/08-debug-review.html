08 / 08

中间结果预览

不必等到全流程运行结束。只要节点已有输出，悬停节点即可通过「预览」图标实时查看表格、报告或图表摘要。

UI: Node Hover Tooltip

单节点快速调试

修改参数后，右键节点选择「调试当前节点」。系统会自动复用上游缓存，秒级呈现调整后的分析结果。

UI: Context Menu -> Debug

版本历史与回滚

每一次保存或运行都会自动生成版本快照。你可以随时在左侧「版本历史」舱中查阅并一键恢复到任意历史时刻。

UI: History Sidebar
