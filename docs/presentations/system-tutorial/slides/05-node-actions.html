04 节点全景：处理节点 Actions

05 / 08
数据清洗 / Data Cleaning
去重 (Dedup)

按全行或指定字段剔除重复记录。

缺失/异常值处理

支持 IQR、百分位或手动规则剔除异常。

编码/缩放

分类变量 One-hot、数值 Min-Max 缩放。

变换与聚合 / Transformation
数据筛选 (Filter)

多条件组合逻辑过滤行。

字段选择 (Selection)

精简分析变量，支持正则匹配。

数据聚合 (Aggregation)

分组统计、窗口函数、时间分桶。

排序与截断

多级排序规则，限制分析样本量。

CORE MULTI-INPUT NODE

数据合并 (Data Merge)

系统中最强大的多输入节点，负责整合碎片化数据。

  • 横向关联 (Join)：按主键（如 SN）将多个来源合并为一张宽表。
  • 纵向追加 (Union)：将结构相同的多个来源按行上下堆叠。
  • 分组集合 (Collection)：不合并表，仅打包为集合供下游批量处理。
💡 进阶：对于复杂的定制化逻辑，可使用 [JS 代码执行] 节点直接编写脚本处理 rows。
