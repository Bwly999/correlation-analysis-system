LAYER 01 分析架构层 Correlation Engine

标准化结果协议

统一消费 NodeResult 协议。通过 kind 标识表格、图表与报告，实现异构算法与 UI 的原子化解耦。

NodeResult Schema

分析算法矩阵

集成皮尔逊、斯皮尔曼、逻辑回归等全矩阵算法。支持 TreeSHAP 因子归因与 VIF 共线性诊断。

Pearson SHAP VIF

结构化见解引擎

自动提取显著因子、风险预警与阅读建议。基于多维指标构建一站式、可读性强的分析报告。

Insights Auto-Report
LAYER 02 UI 交互层 Interaction Layer

响应式分析看板

支持多面板聚合、全屏专注模式。结果 Viewer 根据 Kind 动态匹配（AG-Grid / ECharts / Report）。

异构可视化体系

针对相关性热力图、SHAP 贡献图、分类趋势图等定制化展示。支持采样、归一化与动态交互。

历史回溯预览

完整保留执行快照。支持从运行记录秒级恢复画布状态与结果展示，确保分析链路可回溯。

LAYER 03 工作流引擎 Workflow Logic

拓扑执行器

基于 Vue Flow 的编排。支持运行时补录、单节点调试、冻结输出与多 Trigger 协同调度。

AI 编排主链

结合 MCP 协议。实现从语义需求到工作流计划的自动化生成、校验与画布落图闭环。

声明式节点定义

NodeDefinition 一次声明，自动映射 UI 属性、帮助文档与 AI 模型所需的语义元数据。

LAYER 04 后端服务层 Infrastructure

算法计算集群

Python (FastAPI) 为核心。深度集成 Scikit-learn、XGBoost、SHAP，承接高性能重计算任务。

Node.js 网关

负责 JWT 鉴权、存储隔离、AI 代理转发与 MCP 服务暴露。保障企业级部署安全。

多模态持久化

MySQL + LowDB 双适配。配合 Drizzle ORM，实现版本历史与执行快照的原子化存储。
