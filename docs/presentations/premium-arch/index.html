System Architecture Blueprint

多因子相关性分析系统
架构全景方案

01

分析架构层 (Analysis Layer)

📈 结果协议标准化

统一消费 NodeResult 协议，将表格、图表、指标、报告映射为标准 payload，实现视图与逻辑解耦。

📑 智能报告系统

基于多维数据自动生成包含“结论摘要、阅读指南、适用边界”的结构化报告，赋能业务深度洞察。

🔍 多视角洞察

集成 Pearson/Spearman 单调性分析、SHAP 特征解释、VIF 共线性诊断等全方位分析矩阵。

02

UI 交互层 (UI Layer)

🧱 PrimeVue v4 + Tailwind

采用极简现代 SaaS 风格，Slate-900 专业底色配合 Blue-600 功能强调，提供金融级视觉质感。

🔄 异步视图注册

Viewer 体系动态注册机制，根据结果 Kind 自动匹配渲染组件（AG-Grid / ECharts / Monaco）。

📱 响应式看板

DashboardModal 支持多面板聚合展示、全屏专注模式与浏览器级全屏容器适配。

03

工作流引擎层 (Workflow Layer)

🔗 拓扑执行引擎

基于 Vue Flow 的声明式编排，支持运行时输入补录、单节点调试、冻结输出与历史回溯。

🤖 AI 编排主链

Session 化会话编排，结合 MCP 协议实现“理解需求-召回模板-生成计划-自动落图”的闭环。

📦 声明式节点注册

NodeDefinition 一次声明，自动生成属性弹窗、帮助文档与 AI 提示词元数据。

04

后端服务层 (Backend Layer)

🧠 算法中枢 (Python)

XGBoost, Random Forest, Lasso 等重计算算法由 FastAPI 高性能承接，支持 TreeSHAP 毫秒级解释。

🛡️ 服务网关 (Node.js)

TypeScript 编写的高级适配层，负责 JWT 鉴权、存储隔离、AI 代理转发与 MCP 服务暴露。

💾 持久化矩阵

MySQL + LowDB 双引擎适配，配合 Drizzle ORM 实现高效版本控制与运行历史快照持久化。
