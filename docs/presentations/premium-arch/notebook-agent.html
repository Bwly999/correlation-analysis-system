资源治理三段式

60s 软超时：Atomics 写 SAB → Pyodide 抛 KeyboardInterrupt，优雅收尾。
90s 硬超时：worker.terminate() 强杀，自动重建 Worker 并在 Agent 上下文追加 system message。
120s bridge 兜底：服务端 FrontendBridge 防止前端失联导致工具挂死。

双文件系统协作（关键设计）

持久层 = OPFS：iframe 主线程异步读写，按 notebook-{sessionId}/ 隔离，主站只读展示。
Pyodide 可见层 = MEMFS：Worker 内虚拟 FS，仅 mkdirTree 四个顶级目录，不挂 OPFS。
双向 sync：入向（import_csv / 启动同步）OPFS→MEMFS；出向（exec 后 runtime 主动 snapshotFs 拉回 MEMFS 变更写回 OPFS + 2s 兜底轮询）。
配额：单 session 500MB，每次 fs_write 前 navigator.storage.estimate() 检查，超限返回 quota_exceeded。
