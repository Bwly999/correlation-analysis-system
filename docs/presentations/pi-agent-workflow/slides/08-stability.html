防御层 1: 协议与文档先行
design-doc 特化协议

架构调整必须设计先行。保持设计文档与实现代码的强同步，拒绝无证修改。

固化会话记忆

不依赖 Agent 易逝的会话上下文。核心准则必须沉淀为真实文档，通过代码库硬性约束。

版本化知识迭代

协议与代码共同演进。定期修剪陈旧规约，确保 Agent 始终读取最新可用的方法论。

人机协同友好

无论是新开辟的会话还是新加入的开发者，均能在 5 分钟内通过文档快速接入生产。
