# UX 与交互

本文档定义 Notebook Agent 的产品形态、入口流程、笔记本视图布局、消息流、文件树、错误恢复体验。

---

## 1. 产品定位回顾

> 笔记本是**独立模式**而非画布的辅助工具（决策 Q32：全屏覆盖）。

- 用户启动笔记本 = 进入"AI 数据分析"工作区
- 全屏沉浸式体验，专注分析
- 想看画布得关闭笔记本

这跟"侧推 Drawer"的产品语言完全不同——别用 "drawer" 这个词，UI 上叫**"笔记本视图"**。

## 3. 笔记本视图布局

进入笔记本视图后，主站根容器隐藏，全屏挂 iframe（`/notebook.html?session={sid}`）。

### 3.1 iframe 内的整体布局

```
┌────────────────────────────────────────────────────────────────────────┐
│ ← 关闭笔记本   📓 用户流失因子探索 · session_xxx     [⟳ 重启] [⬇ 下载] │  ← 顶栏
├──────────────────────────────────────────┬─────────────────────────────┤
│                                          │                             │
│  消息流 / 对话面板（左 60%）              │  Workspace 文件树（右 40%）│
│                                          │                             │
│  💭 思考：先了解数据分布                  │  📁 inputs/                │
│  🔧 python_exec_inline                   │  │  ├── upstream.csv       │
│     ├ 代码片段（折叠）                    │  │  └── upstream.meta.json │
│     ├ stdout 流式输出                    │  📁 scripts/                │
│     └ ✓ 完成 234ms                       │  │  ├── 01_explore.py     │
│                                          │  │  └── 02_corr.py        │
│  📊 [图：分布概览（缩略）]                │  📁 artifacts/              │
│                                          │  │  ├── fig_dist.png ⭐    │
│  💭 思考：异常集中在尾部                  │  │  └── corr_matrix.csv   │
│  🔧 fs_write reports/main.md             │  📁 reports/                │
│     ✓ 写入 §3                            │  │  └── main.md ⭐         │
│                                          │                             │
│  ❓ ask_user: 是否需要做 Lasso 筛选？     ├─────────────────────────────┤
│     [是] [否] [让 Agent 决定]            │  文件预览（点击文件树切换）│
│                                          │                             │
│                                          │   [ 当前选中文件的渲染 ]   │
│                                          │                             │
├──────────────────────────────────────────┤                             │
│  📋 TODO（折叠）                         │                             │
│  ✓ 数据概览                              │                             │
│  → 单调性分析                            │                             │
│  ○ 多因子建模                            │                             │
│  ○ 形成结论                              │                             │
│                                          │                             │
├──────────────────────────────────────────┴─────────────────────────────┤
│ 🐍 Python · 内存 234MB / 4GB · 12 个 cell · 5min · [⏹ 停止]             │  ← 状态条
├────────────────────────────────────────────────────────────────────────┤
│  [输入消息...]                                          [⏎ 发送]      │  ← 输入框
└────────────────────────────────────────────────────────────────────────┘
```

### 3.2 顶栏

- **关闭按钮**（左上）：关闭整个笔记本视图回到画布。如果 Agent 正在跑会弹确认。
- **session 标题**（中间）：默认 "新建分析" + 时间戳；Agent 可以通过 system 工具修改（M2）；M1 用户在顶栏可重命名。
- **重启 Python 环境**：按钮，显式重启 Worker（销毁 kernel，workspace 文件保留）。
- **下载工作区 zip**：把整个 OPFS 当前 session 目录打包下载。

### 3.3 三栏布局

| 栏 | 宽度 | 内容 |
|----|------|------|
| 消息流（左）| 60% | Pi Agent 对话流（用户消息 / Agent 思考 / 工具卡片）|
| 文件树 + 预览（右上 + 右下）| 40% | 上半部分文件树，下半部分文件预览；预览面板可拖动调高 |

支持**拖动调宽**：拖左右栏分隔线，比例记忆到 localStorage。

### 3.4 环境状态条

底部状态条（决策 Q17 不限总预算，UI 必须暴露状态）：

```
🐍 Python · 内存 234MB · 12 个 cell · 5min · [⏹ 停止]
```

字段含义：

- `内存 234MB` —— Worker 内 `performance.memory.usedJSHeapSize` 估算
- `12 个 cell` —— 累计 python_exec_* 调用次数
- `5min` —— session 创建至今的实际"Agent 工作时长"（不计用户阅读时间）
- `[⏹ 停止]` —— 中断当前正在跑的 exec / 让 Agent 停止当前 turn

## 4. 首次加载体验

决策 Q9：中心进度条阻塞。

### 4.1 加载阶段

iframe 启动后渲染**全屏加载页**，覆盖整个视图：

```
┌────────────────────────────────────────────────┐
│                                                │
│              📓 准备 Python 环境                │
│                                                │
│        ▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░░░░░  62%             │
│                                                │
│        正在加载：pandas (12.3 / 100 MB)         │
│                                                │
│        首次加载约需 30-90 秒，                  │
│        之后浏览器会缓存，下次秒开。             │
│                                                │
│              [取消]                            │
│                                                │
└────────────────────────────────────────────────┘
```

进度阶段（来自 Worker 的 `init_progress` 事件）：

| stage | 阶段名 | 进度估算 |
|-------|--------|---------|
| `load_runtime` | 加载 Pyodide 运行时 | 0-30% |
| `load_packages` | 加载 numpy/pandas/... | 30-90%（按包加权）|
| `mount_fs` | 挂载文件系统 | 90-95% |
| `lock_sandbox` | 锁定沙箱 | 95-100% |

### 4.2 加载失败

如果 init_failed 事件触发：

```
┌────────────────────────────────────────────────┐
│              ⚠️ Python 环境加载失败              │
│                                                │
│   网络错误：无法加载 /pyodide/v0.27/pandas.whl │
│                                                │
│         [重试]      [关闭笔记本]              │
│                                                │
│  如果反复失败，请联系管理员检查 Pyodide        │
│  资源是否正确部署。                            │
└────────────────────────────────────────────────┘
```

### 4.3 加载成功

进度到 100% 后，遮罩淡出（300ms），用户看到主三栏布局，输入框 focus，提示文案：

```
✨ 准备就绪。Agent 已就位，告诉我你的分析目标。
```

## 6. Workspace 文件树

### 6.1 视觉

```
📁 inputs/                              [3]
│  ├── upstream.csv                12.3 KB
│  └── upstream.meta.json           0.4 KB
│
📁 scripts/                             [2]
│  ├── 01_explore.py                1.2 KB
│  └── 02_corr.py                   2.4 KB  ⭐ 修改于 14:32
│
📁 artifacts/                           [2]
│  ├── fig_dist.png                23.4 KB  ⭐
│  └── corr_matrix.csv              4.7 KB
│
📁 reports/                             [1]
│  └── main.md                      4.3 KB  ⭐ 修改于 14:35
```

设计要点：

- 顶级目录固定为 4 个（inputs/scripts/artifacts/reports），不可创建其他顶级目录
- 文件按 mtime 倒序
- 最近 30s 内变更的文件标 ⭐ 高亮
- 鼠标悬停显示工具栏：[👁 预览] [⬇ 下载] [📋 拷路径]
- 单击 = 打开预览
- 双击 = 在新 tab 打开（M2）
- 右键不实现（避免与浏览器原生菜单冲突）

### 6.2 刷新机制

决策 Q31：主页 2s 轮询 OPFS 列目录。

```typescript
// src/notebook/composables/useWorkspaceTree.ts
export const useWorkspaceTree = (sessionId: string) => {
  const tree = ref<TreeNode | null>(null)
  let timer: number | null = null

  const refresh = async () => {
    const next = await listOpfsTree(sessionId)
    if (!isEqual(tree.value, next)) {
      tree.value = next
    }
  }

  onMounted(() => {
    refresh()
    timer = window.setInterval(refresh, 2000)
  })
  onBeforeUnmount(() => {
    if (timer) clearInterval(timer)
  })

  // iframe 主动通知时立即刷新（低延迟优化）
  onWorkspaceChanged(() => {
    refresh()
  })

  return { tree, refresh }
}
```

### 6.3 单文件操作

每个文件节点 hover 时显示三个图标：

- **预览**：在右下面板渲染
- **下载**：触发浏览器下载（生成 blob URL）
- **拷路径**：复制相对路径到剪贴板（Agent 可能需要用户读路径）

不提供"删除"按钮（M1）—— 避免用户误删 Agent 的工作产物。

## 7. 文件预览面板

预览面板根据文件类型路由到不同 viewer。

### 7.1 路由表

| 扩展名 | viewer | 备注 |
|--------|--------|------|
| `.md` | MarkdownPreview | 走 sanitize；图引用解析为 OPFS blob URL |
| `.py .js .ts .json .yml .toml .txt` | MonacoReadonly | 语法高亮 |
| `.png .jpg .svg` | ImageViewer | 缩放 / 适配 |
| `.csv .tsv` | AgGridTablePreview | 复用既有；前 1000 行 |
| `.parquet .arrow .feather` | ParquetPreview | M1 简版 —— 用 pyodide 子线程读 head；或先不支持，仅显示文件信息（M1 推荐后者）|
| `.echarts.json` | EChartsPreview | M2；M1 落到 JSON 走 MonacoReadonly |
| 其他 | FileMetaCard | 显示大小 / mtime / "格式不支持预览" |

### 7.2 Markdown 预览特殊行为

- 显示 `reports/main.md` 时，左侧显示目录大纲（H1 / H2 锚点）
- 图片 `![](../artifacts/xxx.png)` → 主站从 OPFS 读取该 png → 转 blob URL → 替换 src
- 链接 `[xx](path)` → 点击切换到对应文件预览

### 7.3 加载状态

切换文件时显示骨架屏（200ms 内不闪），避免空白闪烁。

## 8. 错误恢复体验

### 8.1 Worker 崩溃 / 硬超时

iframe 重启 Worker（30s 内）：

```
┌──────────────────────────────────────────────────────┐
│  ⚠ Python 环境已重启                                 │
│  之前的变量已清空，Workspace 文件保留。               │
│  Agent 将在下次执行时重新加载所需数据。               │
└──────────────────────────────────────────────────────┘
                                                  [×]
```

吐司样式，5s 自动消失。同时：

- 状态条显示 "🐍 Python · 已重启 · 0 个 cell"
- iframe 调 `POST /api/notebook-agent/sessions/:id/system-message` 注入 system message 给 Agent

### 8.2 OPFS 配额耗尽

```
┌──────────────────────────────────────────────────────┐
│  ⚠ 工作区已达配额上限（500MB）                       │
│  Agent 无法继续写入。建议：                          │
│  - 让 Agent 用 fs_edit 替代 fs_write 节省空间        │
│  - 让 Agent 删除中间文件 (M2)                        │
│  - 或下载工作区然后开启新 session                    │
└──────────────────────────────────────────────────────┘
                                                  [×]
```

### 8.3 工具调用错误

工具卡片显示错误状态：

```
┌──────────────────────────────────────────────────────┐
│ 🔧 fs_read xxx.csv · ✗ 失败                         │
│ ─────────────────────────────────────────────────── │
│ ⚠ 路径越界                                          │
│ 路径必须以 inputs/scripts/artifacts/reports 之一开头 │
│ 得到 "data.csv"                                      │
└──────────────────────────────────────────────────────┘
```

红色边框 + ✗ 图标。这种错误让 Agent 自己看到回执后修正。

### 8.4 网络中断

iframe 顶部显示横幅：

```
🟡 服务连接中断，正在重连...
```

EventSource 自动重连；重连成功后横幅消失。

### 8.5 服务端 Agent 失败

```
┌──────────────────────────────────────────────────────┐
│  ⚠ Agent 推理失败                                    │
│  上下文：调用 LLM 时返回 503                         │
│  你可以重发刚才的消息或重启 session。                 │
│         [重试]    [关闭并重启]                       │
└──────────────────────────────────────────────────────┘
```

## 9. 关闭笔记本

### 9.1 关闭按钮

顶栏左上角的 `← 关闭笔记本` 按钮。

### 9.2 退出确认

如果当前**正在跑 exec** 或 **Agent 正在 streaming**：

```
┌──────────────────────────────────────────────────────┐
│  ⚠ Agent 还在工作                                    │
│  关闭后当前操作会被中断，工作区文件不丢失。           │
│  下次仍可从顶部菜单进入此 session。                   │
│         [取消]              [仍然关闭]              │
└──────────────────────────────────────────────────────┘
```

### 9.3 关闭后

- 销毁 iframe DOM
- iframe 内 Worker 自动销毁

## 10. 快捷键

| 快捷键 | 行为 |
|--------|------|
| `⌘/Ctrl + Enter` | 输入框发送消息 |
| `Esc` | 关闭笔记本（同点关闭按钮，走确认）|
| `⌘/Ctrl + K` | focus 输入框 |
| `⌘/Ctrl + R` | 重启 Python 环境（弹确认）|
| `⌘/Ctrl + S` | 下载 workspace zip |

不绑全局快捷键，仅在 iframe focus 时生效。

## 12. 视觉语言

延续主站 Slate-900 + Blue-600 + Tailwind v4 的视觉体系。

笔记本特有的语义色：

| 用途 | 色值 |
|------|------|
| Agent 思考块（thinking）| `slate-500` 文字 + `slate-50` 背景 |
| 工具调用成功 | `emerald-600` 状态点 |
| 工具调用失败 | `rose-600` 状态点 |
| ask_user 卡片 | `blue-600` 边框 + 渐变蓝 |
| TODO in_progress | `amber-500` |
| TODO completed | `emerald-600` |
| 文件标记新变更 | `amber-500` ⭐ |

避免大面积使用图标 emoji（一致性差），保留 emoji 仅用于关键语义入口（💭 思考、🔧 工具、📁 目录、❓ 提问、⚠ 错误）。
