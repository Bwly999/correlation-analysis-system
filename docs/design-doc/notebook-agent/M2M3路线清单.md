## 一、M2（下一期）

### 1. 工具集（工具集协议.md §1.2）

| 工具 | 用途 | 文档位置 |
|------|------|---------|
| `python_kernel_reset` | Agent 主动重置 Python kernel（清空内存变量），不必靠用户手动重启 Worker | 工具集协议.md §1.2；执行模型.md §4.1 L202、§5.4 L247 |
| `python_install` | 放开 micropip 白名单安装（M1 全禁，M2 白名单） | 执行模型.md §4.1 L207-212；安全模型.md §6.3 L270-278 |
| `chart_save_echarts` | Agent 直接产出 ECharts spec（`.echarts.json`），预览面板渲染 | 工具集协议.md §1.2；架构与数据流.md L342 |

### 2. UX / 交互

- **session 标题**：Agent 通过 system 工具修改（UX §3.1 L112）
- **双击文件 = 新 tab 打开**（UX L377）
- **ECharts 预览**：`.echarts.json` → EChartsPreview 组件（UX §7.1 L439）
- **恢复 session 入口**：M1 不做，M2 加最近笔记本列表 / 恢复入口（UX L550；架构与数据流.md §4.4 L442）
- **Agent 删中间文件**（UX L481）

### 3. 安全

- **Permissions-Policy**：`<iframe>` 加 `allow="..."` 收紧不需要的能力（安全 §4.4 L133-137）
- **micropip 白名单**：M2 放开受限安装（安全 §6.3 L270-278）
- **手动 redteam 演练**：M2 之前安排一次人工渗透，报告归档到 `docs/security/redteam/`（安全 §9.2 L411-420）
- **ECharts JSON zod 校验**：渲染前用 zod 校验 spec（安全 §10 L456-461）

### 4. 数据接入

- **多源命名调整**：M2 放开多源后，`inputs/<sourceKind>_<safeName>.csv`（数据接入 §6.1 L289-291）
- **Agent 中途追加数据**（数据接入 §8 L359）

### 5. 部署 / 构建

- **埋点**：可选 M1，建议 M2（部署与构建.md §9.3 L623-629）
- **Nginx + 静态托管**配置示例（部署与构建.md §3.4 L216-224，当前是 Fastify）
- **不预装包**：duckdb / pyarrow / networkx 作为 M2/M3 候选按需加（部署与构建.md §4.2 L268-271）

### 6. 验收 / 基线

- **性能基线 E2E**（Playwright）：加载性能（Pyodide 冷启动 ≤90s / SW 缓存 ≤5s）+ 执行性能（python_exec / pandas import / df.describe / plt.savefig）—— M1 用单测覆盖 fs 层 + Markdown 层，加载/执行层需真实 Pyodide，属 E2E（验收与基线.md §2.4）
- **E2E 覆盖广度**：验收 Gate 1-15 大量标"E2E"，M1 仅 `e2e/notebook-bootstrap-race.spec.mjs`（竞态回归）；Gate 1-15 的完整 Playwright 脚本待 M2 补
- **已知局限**：M2 路线图见验收与基线.md §4.2（L217-241）

## 三、M2 启动前的核对清单

进入 M2 开发时，先确认以下 M1 基础是否稳定（避免在沙地上盖楼）：

- [ ] M1 全部验收 Gate 1-18 通过（含 E2E）
- [ ] 红队 20 项自动化 gate 持续绿
- [ ] 性能基线无回归
- [ ] 至少一次真实用户走查验收路径（§1.1 端到端场景 15 步）
- [ ] 审计日志在真实使用中产出可用排查数据
