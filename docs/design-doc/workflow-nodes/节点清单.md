# 节点清单

本文档列出当前注册的所有节点，包含类别、availability、libraryGroup 和输出类型。

> 节点定义协议见 [节点定义与属性](节点定义与属性.md)，创建规范见 [创建新节点](创建新节点.md)。
> 如需连接规则和执行引擎细节，见 `../workflow-system/` 目录。

关联代码：`src/nodes/registry.ts`、`src/nodes/definitions/`

---

## Trigger 节点（3 个）

数据源/运行时入口。

### `file-import` / 本地文件导入

| 属性 | 值 |
|------|-----|
| category | `trigger` |
| availability | `active` |
| libraryGroup | `import-data` |
| output kind | `table` |

- 读取 CSV、Excel、JSON
- 解析改为纯前端后台任务，导入期间不阻塞主界面交互
- 支持阶段性进度提示与主动取消；取消后不会写入半成品输出
- 完成后统一补齐字段 `schema`、行数摘要和轻量预览摘要

### `manual-json-import` / 手动输入数据

| 属性 | 值 |
|------|-----|
| category | `trigger` |
| availability | `active` |
| libraryGroup | `import-data` |
| output kind | `table` 或 `json` |

- 直接输入 JSON 文本
- 常用于调试、构造最小测试样例
- 对象数组输出 `table`，其他合法 JSON 输出 `json`

### `neighbor-system` / 看板数据对接

| 属性 | 值 |
|------|-----|
| category | `trigger` |
| availability | `active` |
| libraryGroup | `import-data` |
| output kind | `table` |

- 从外部看板系统拉取业务数据
- 支持时间、方案、SN、任务令等多种启动方式
- 先选产品、场景和因子全集，再在运行时按启动方式与工序范围拉取数据
- 默认 mock 桥接提供覆盖涂布、辊压、分切、卷绕、装配、注液、化成、分容、PACK 的工序与 40 个因子，方便本地演示和交互测试
- 按 SN 查询时，SN 列表既支持手动输入，也支持从 CSV / Excel 导入并选择列回填；导入跳过空值，默认去重
- 若项目以 iframe 方式嵌入宿主页面，宿主必须先传入 token

## Action 节点（12 个，含 2 legacy）

中间处理节点。

### 活跃节点

#### `data-dedup` / 去重

| 属性 | 值 |
|------|-----|
| availability | `active` |
| libraryGroup | `clean-filter` |
| output kind | `table` |

- 按整行或按字段组合去重
- 支持保留首条或末条（基于当前表格顺序）

#### `data-missing-outlier` / 缺失/异常值处理

| 属性 | 值 |
|------|-----|
| availability | `active` |
| libraryGroup | `clean-filter` |
| output kind | `table` |

- 统一识别真实 `undefined`、`null`、空字符串，及字符串 `"undefined"` / `"null"` 等常见空值占位
- 异常值支持三种模式：**IQR 四分位距**、**百分比剔除**、**手动区间**
  - IQR — 通过 IQR 系数 k 控制剔除强度
  - 百分比 — 通过百分位值（如 1%）截断两端
  - 手动区间 — 可配置多组字段上下限规则（> 下限且 < 上限），规则间按 AND 生效
- 目标字段留空时自动处理所有可识别的字段

#### `data-encoding-scaling` / 编码/缩放

| 属性 | 值 |
|------|-----|
| availability | `active` |
| libraryGroup | `clean-filter` |
| output kind | `table` |

- 分类变量编码与数值字段缩放
- 默认使用 Z-Score 标准化；可切换 Min-Max 归一化

#### `data-filter` / 数据筛选

| 属性 | 值 |
|------|-----|
| availability | `active` |
| libraryGroup | `clean-filter` |
| output kind | `table` |

- 多条件过滤与规则组合（全部满足 / 任一满足）
- 支持字符串、数值、空值等多种比较操作

#### `field-selection` / 字段选择

| 属性 | 值 |
|------|-----|
| availability | `active` |
| libraryGroup | `field-shaping` |
| output kind | `table` |

- 保留或排除指定字段
- 支持普通搜索和正则搜索（`allowRegexSearch: true`）选择字段
- 包含 / 不包含两种模式

#### `sort` / 排序

| 属性 | 值 |
|------|-----|
| availability | `active` |
| libraryGroup | `field-shaping` |
| output kind | `table` |

- 按多个优先级规则排序，支持升序和倒序

#### `data-limit` / 数据量限制

| 属性 | 值 |
|------|-----|
| availability | `active` |
| libraryGroup | `field-shaping` |
| output kind | `table` |

- 截断表格数据量，支持保留最前面或最后面的 n 条

#### `js-transform` / JS 代码执行

| 属性 | 值 |
|------|-----|
| availability | `active` |
| libraryGroup | `field-shaping` |
| output kind | `table` |

- 单输入同步代码转换节点
- 代码里只暴露 `rows` 变量（数组对象列表）
- 必须 return 数组对象列表
- 固定输出 `table`

#### `data-aggregation` / 数据聚合

| 属性 | 值 |
|------|-----|
| availability | `active` |
| libraryGroup | `merge-aggregate` |
| output kind | `table` |

- 四种聚合模式：行内合并、分组统计、按行滚动窗口、按时间窗口分桶

#### `data-merge` / 数据合并

| 属性 | 值 |
|------|-----|
| availability | `active` |
| libraryGroup | `merge-aggregate` |
| inputMode | `multiple` |
| minInputs | 2 |
| output kind | `table` 或 `tableCollection` |

- 核心多输入节点
- 三种合并模式：纵向追加（`append`）、横向关联（`join`）、分组集合（`collection`）
- 横向关联：`unifiedKeyName` 定义统一主键，`keyMappings` 为每来源指定 mergeKey
- 横向关联执行时移除各来源原始 key 字段，仅保留 `unifiedKeyName`

## Terminal 节点（15 个，含 5 legacy）

分析终点，不可输出连线。

### 活跃节点（10 个）

#### `correlation-analysis` / 单调性分析

| 属性 | 值 |
|------|-----|
| libraryGroup | `stat-analysis` |
| output kind | `report` |
| 计算位置 | 前端本地执行 |

- 分析因子与目标值的单调性关系
- 支持 Pearson / Spearman / Kendall 三种方法切换，默认 Pearson
- X 字段 / Y 字段交叉计算
- 输出热力图、Top N 排行、结果可信提示和相关明细
- 运行前校验字段存在性、数值类型，样本不足时报错

#### `vif` / VIF 共线性检测

| 属性 | 值 |
|------|-----|
| libraryGroup | `stat-analysis` |
| output kind | `report` |
| 计算位置 | 前端本地执行 |

- 多重共线性诊断
- 输出检测摘要、VIF 排序、风险提示与字段明细

#### `pca` / PCA 主成分分析

| 属性 | 值 |
|------|-----|
| libraryGroup | `stat-analysis` |
| output kind | `report` |
| 计算位置 | 前端本地执行 |

- 输出分析摘要、解释方差占比、字段载荷热力图与载荷明细

#### `anova` / 方差分析

| 属性 | 值 |
|------|-----|
| libraryGroup | `stat-analysis` |
| output kind | `report` |
| 计算位置 | 前端本地执行 |

- 单因素方差分析
- 输出 F 值 / P 值、分组均值对比、分组箱线图与分组明细

#### `classification-factor-screening` / 分类因子筛查

| 属性 | 值 |
|------|-----|
| libraryGroup | `stat-analysis` |
| output kind | `report` |
| 计算位置 | 前端本地执行 |

- 二分类或多分类标签的因子筛查
- 自动区分数值因子（差异检验）和类别因子（关联检验）
- 输出显著性排行、检验明细和风险提示

#### `xgboost-shap` / XGBoost + SHAP

| 属性 | 值 |
|------|-----|
| libraryGroup | `model-analysis` |
| output kind | `report` |
| 计算位置 | 调用后端 Python |

- 调用后端分析接口，按回归任务实现
- `maxDependencePlots` 控制 SHAP 趋势图数量，默认前 8 个
- 支持建模前异常值处理：不处理 / IQR 剔除 / 孤立森林
- 高级参数：树数量、学习率、树深、测试集比例、随机种子、SHAP 采样上限、自动调参策略

#### `lasso` / Lasso 回归

| 属性 | 值 |
|------|-----|
| libraryGroup | `model-analysis` |
| output kind | `report` |
| 计算位置 | 调用后端 Python |

#### `multiple-linear-regression` / 多元线性回归

| 属性 | 值 |
|------|-----|
| libraryGroup | `model-analysis` |
| output kind | `report` |
| 计算位置 | 调用后端 Python |

- 输出模型摘要、回归系数排序、预测值对比与残差分布

#### `random-forest-feature-importance` / 随机森林特征重要性

| 属性 | 值 |
|------|-----|
| libraryGroup | `model-analysis` |
| output kind | `report` |
| 计算位置 | 调用后端 Python |

- 输出特征重要性排行、累计重要性、预测值对比与结果解读提示

#### `logistic-regression-classification` / 逻辑回归分类分析

| 属性 | 值 |
|------|-----|
| libraryGroup | `model-analysis` |
| output kind | `report` |
| 计算位置 | 调用后端 Python |

- 支持二分类和多分类
- 输出模型摘要、分类指标、混淆矩阵、ROC 曲线（二分类）和系数解释
