# 附录：历史补充说明

本文档记录与节点相关的历史变更和补充约束。

---

## 2026-03-25

### data-merge 横向关联模式变更

- 原独立"字段合并"节点已移除，能力收敛到 `data-merge` 的"横向关联"模式
- `data-merge` 横向关联配置协议：
  - `unifiedKeyName` — 合并后统一保留的主键字段名称
  - `keyMappings` — 每个上游来源的来源键字段 `mergeKey`
- 横向关联执行时移除各来源原始 key 字段，仅保留 `unifiedKeyName` 为统一主键

---

## 2026-03-22

### AI 编排约束

- 节点自动编排首期只允许从现有节点库创建实例，不允许动态生成新的节点定义
- LLM 编排优先消费 `NodeDefinition.help` 与 `assistantHints`，新增节点应持续补齐这两类信息
- AI 计划在应用前校验节点类型、连接规则、输入模式与引用合法性，节点定义中的类别、输入限制和默认配置必须保持准确
