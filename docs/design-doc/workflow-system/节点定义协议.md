# 节点定义协议

本文档描述 `NodeDefinition` 接口。所有节点通过 `src/nodes/types.ts` 中的 `NodeDefinition` 声明式注册。

> 关于节点分类体系请见 [节点体系](节点体系.md)，关于字段设计、属性类型、创建步骤与实现规范请看 `../工作流节点说明.md`。

## NodeDefinition 接口

```ts
export interface NodeDefinition<TInput = any, TConfig = Record<string, any>, TOutput = any> {
  name: string
  displayName: string
  icon: string
  category: 'trigger' | 'action' | 'terminal'
  description: string
  help?: NodeHelpDoc
  assistantHints?: NodeAssistantHints
  libraryGroup?: NodeLibraryGroupId
  libraryAliases?: string[]
  libraryKeywords?: string[]
  availability?: 'active' | 'legacy'
  isLegacy?: boolean
  properties: NodeProperty[]
  inputMode?: 'single' | 'multiple'
  minInputs?: number
  maxInputs?: number | null
  execute: (input: TInput, config: TConfig) => Promise<TOutput> | TOutput
}
```

## 关键字段说明

| 字段 | 影响范围 |
|------|---------|
| `category` | 连接权限与全局运行行为 |
| `help` | 帮助中心与节点配置弹窗中的用户帮助内容 |
| `assistantHints` | AI Agent 自动建节点、自动建工作流的结构化提示 |
| `availability` | 声明节点是否对"新建工作流"可见；`legacy` 仅用于历史兼容 |
| `inputMode` / `minInputs` / `maxInputs` | 输入协议（详见[多输入协议](多输入协议.md)） |
| `execute()` | 输出必须进入标准结果协议（详见[结果协议](结果协议.md)） |
| `libraryGroup` / `libraryAliases` / `libraryKeywords` | 节点库搜索和分组 |
| `icon` | 画布节点图标 |

## 系统级关注点

- **category**：决定连接权限（见[连接规则](连接规则.md)）与全局运行行为（见[执行引擎](执行引擎.md)）
- **help**：同时服务于帮助中心和节点配置弹窗，`help.summary` 复用为节点分类索引摘要
- **availability**：`'active'` 表示新建工作流可见，`'legacy'` 仅用于已存在工作流的兼容显示
- **execute()**：所有节点执行的统一入口，输出必须经过 `normalizeNodeResult()` 标准化

## 注册机制

节点定义在 `src/nodes/registry.ts` 集中注册，附带 `attachNodeHelp()` 自动注入帮助文档。
