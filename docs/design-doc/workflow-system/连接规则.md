# 连接规则

本文档描述工作流的连接约束和画布交互约定。连接规则由 `workflowStore.ts` 中的 `CONNECTION_RULES` 与节点输入限制共同决定。

## 类别级连接规则

| 连接方向 | 是否允许 |
|----------|---------|
| Trigger → Action | ✅ |
| Trigger → Terminal | ✅ |
| Action → Action | ✅ |
| Action → Terminal | ✅ |
| Terminal → 任何节点 | ❌ |

### 硬性限制

- Terminal 节点不能继续向下输出连线
- 节点不能回连到 Trigger
- 当前没有单独的 Model 类别，分析终点统一归到 `terminal`

## 输入数量规则

| 规则 | 说明 |
|------|------|
| 默认输入 | 单输入（`inputMode = 'single'`） |
| 多输入 | 必须显式声明 `inputMode = 'multiple'` |
| 数量限制 | `minInputs` / `maxInputs` 控制上下限 |
| 连线校验 | `validateConnection()` 中完成 |
| 当前多输入节点 | `data-merge` |

多输入协议详情请见 [多输入协议](多输入协议.md)。

## 全局运行目标选择规则

全局运行时：

1. 若存在 Terminal 节点，则优先执行所有 Terminal 节点
2. 若不存在 Terminal 节点，则退化为执行所有叶子节点

这样同时覆盖：
- **标准分析流**：执行到终点节点
- **调试流**：仅由中间节点组成的流程也能独立执行

## 画布交互约定

### 基本操作

| 操作 | 行为 |
|------|------|
| 单击节点 | 只负责选中节点，不再直接打开配置 |
| 双击节点主体 | 打开节点设置弹窗 |
| 双击节点标题 | 进入重命名 |
| `Ctrl`/`Meta` + 单击 | 持续追加或取消多选 |
| `Ctrl`/`Meta` + 左键拖拽 | 框选多个节点 |
| 多选节点拖动 | 复用 Vue Flow 原生多选拖拽行为，支持一起拖动 |

### 快捷键

| 快捷键 | 行为 |
|--------|------|
| `Ctrl`/`Meta` + `C` | 复制当前选中节点，在画布中直接生成副本；同时更新会话内画布剪贴板 |
| `Ctrl`/`Meta` + `D` | 复制当前选中节点为文本协议，面向跨工作流或跨页面传递 |
| `Ctrl`/`Meta` + `V` | 优先尝试从系统剪贴板解析文本协议；若不是，则回退到会话内画布剪贴板 |
| `Ctrl`/`Meta` + `Delete` | 删除当前选中节点及相关连线 |

### 复制 / 粘贴协议

文本复制使用 `workflow-selection` 协议，包含以下字段：

- `kind` — 协议标识
- `version` — 协议版本
- `nodes` — 选中节点列表
- `edges` — 选中节点间的内部连线

关键行为：

- 选区快照只保留选中节点及内部连线
- 复制与粘贴主动剥离运行态信息（`status`、`output`、`logs`、运行时输入）
- 粘贴时统一重建节点 id 与连线 id，按目标锚点整体偏移

### 连线视觉约定

- 自定义 `n8n` edge 类型
- Bezier 曲线路径
- 状态色与悬浮态使用 Slate / Blue / Emerald / Rose 色系
