# 持久化与历史快照

本文档描述工作流的持久化模型、版本管理、历史记录与存储模式。

## SavedWorkflow 模型

持久化模型结构：

| 字段 | 说明 |
|------|------|
| `id` | 工作流 ID |
| `name` | 工作流名称 |
| `updatedAt` | 最后更新时间 |
| `nodes: WorkflowNodeSnapshot[]` | 节点快照列表 |
| `edges: Edge[]` | 连线列表 |

### 保存前序列化

`serializeWorkflowNodes()` 处理逻辑：

- 节点状态重置为 `idle`
- 只有冻结节点保留输出（详见[执行引擎](执行引擎.md)）

### 导出行为

导出工作流 JSON 时：

- 补齐默认配置，状态重置为 `idle`
- 不保留运行缓存，包括冻结节点输出
- 目标是"可再次导入并恢复结构与配置"

## 脏检查

编辑态维护"最近一次已保存快照"签名：

- 节点、连线、名称变化触发未保存状态
- 不把 `selected`、`dragging` 等瞬时画布状态计入已修改
- 加载/导入时补齐节点默认配置，避免首次运行时误判
- 新建空白工作流默认干净；导入 JSON 后默认未保存
- 页面关闭/切换工作流/导入/新建前提示"保存并继续 / 不保存 / 取消"

## 存储模式

### 模式切换

| 模式 | 存储后端 | 环境变量控制 |
|------|---------|-------------|
| **local** | 浏览器 localStorage | 默认 |
| **server** | 服务端持久化，按用户隔离 | `WORKFLOW_STORAGE_BACKEND` |

### Server 模式后端实现

| 后端 | 适用场景 | 说明 |
|------|---------|------|
| `lowdb` | 单机部署 | 文件落盘，使用 `WORKFLOW_STORAGE_DATA_DIR` |
| `mysql` | 多实例共享 | Drizzle ORM schema + 迁移文件管理 |

### Server 模式附加能力

- 可选 JWT 鉴权（`WORKFLOW_JWT_SECRET`），基于 `jose` HS256
- 请求头自动附加 `Authorization`、`x-workflow-user-id`、`x-workflow-user-name`
- JWT 解析在 `src/server/auth/jwtAuth.ts`，前端 token 获取在 `src/services/apiAuth.ts`
- 中文用户名做百分号编码再写入请求头

## 工作流版本模型

每次"保存"和"回滚"都会生成版本快照。版本协议定义在 `src/utils/storage/types.ts`。

### 类型

| 类型 | 说明 |
|------|------|
| `WorkflowVersionMetadata` | `id`、`workflowId`、`createdAt`、`source: 'save' \| 'rollback'` |
| `WorkflowVersionDetail` | 元数据 + 完整 `workflow: SavedWorkflow` |
| `WorkflowRollbackResult` | `workflow` + `version` |

### 约束

- `saveWorkflow()` 成功后存储层追加 `source = 'save'` 快照
- 回滚时先恢复目标快照，再追加 `source = 'rollback'` 版本
- server 模式接口：`GET /versions`、`GET /versions/:versionId`、`POST /versions/:versionId/rollback`
- local 模式写入本地 `workflow_versions` 存储键

## 历史记录模型

`ExecutionRecord` 结构：

| 字段 | 说明 |
|------|------|
| `id` | 记录 ID |
| `workflowId` | 所属工作流 |
| `workflowName` | 工作流名称 |
| `startTime` | 执行开始时间 |
| `duration` | 执行耗时 |
| `status` | 执行状态 |
| `nodes: WorkflowNodeSnapshot[]` | 执行时的节点快照 |
| `edges: Edge[]` | 执行时的连线快照 |

## 历史快照保存策略

| 策略 | 规则 |
|------|------|
| 列表容量 | 保留最近 20 条 |
| 节点输出 | 按完整结果保存（`table`、`report`、`chart` 等完整 payload） |
| 引用隔离 | 历史快照做独立深拷贝，不与编辑态共用引用 |

## 历史模式

- 画布切换到历史快照，原始编辑态暂存
- UI 进入只读语义
- 可退出并恢复编辑态
