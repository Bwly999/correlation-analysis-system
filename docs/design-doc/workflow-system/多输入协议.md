# 多输入协议

本文档描述多输入节点的数据协议。定义在 `src/nodes/types.ts`。

> 前置阅读：[节点定义协议](节点定义协议.md) — 了解 `inputMode`、`minInputs`、`maxInputs` 字段

## 数据结构

### MultipleNodeExecutionItem

```ts
export interface MultipleNodeExecutionItem<TResult = NodeResult | null> {
  sourceNodeId: string
  sourceNodeLabel: string
  edgeId?: string
  order?: number
  result: TResult
}
```

### MultipleNodeExecutionInput

```ts
export interface MultipleNodeExecutionInput<TResult = NodeResult | null> {
  inputs?: Array<MultipleNodeExecutionItem<TResult>>
}
```

## 关键约束

- 多输入节点统一消费 `inputs[].result`
- `result` 必须是已标准化的 `NodeResult`
- 不再向多输入节点透传旧版 `payload` alias

## 实现要点

当一个节点声明 `inputMode: 'multiple'` 时，执行引擎在调用 `execute()` 前会组装 `MultipleNodeExecutionInput` 结构，包含所有上游节点的标准化结果。

当前核心多输入节点为 `data-merge`。
