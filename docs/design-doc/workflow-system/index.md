## 系统定位

这是一个多因子相关性分析工作流系统，交互形态接近 n8n：

- 用户在画布中拖拽、连接节点构建流程
- **Trigger** 节点提供数据源或运行时入口
- **Action** 节点负责中间处理与数据变换
- **Terminal** 节点负责生成最终分析结果

系统当前有两层核心标准化：

- **节点定义标准化**：所有节点通过 `NodeDefinition` 声明式注册
- **结果协议标准化**：节点输出统一使用 `NodeResult`
