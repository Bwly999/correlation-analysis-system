# 性能与构建策略

本文档描述工作流系统的性能优化措施和 Vite 构建切包策略。

## 运行态性能

| 措施 | 说明 |
|------|------|
| `markRaw` | 节点输出写入前统一经过 `markRaw`，避免 Vue 响应式代理开销 |
| 快照截断 | 历史快照主动截断超大结果 |
| 无固定延时 | 执行链路不内置固定延时 |
| 日志数量限制 | 日志区仅保留最近 500 条 |

## 懒加载

以下组件已异步加载：

- `DataDisplayPanel.vue` 中的 `MonacoEditor`
- `PropertyField.vue` 中的 `MonacoEditor`
- `viewers/registry.ts` 中的各类结果 viewer
