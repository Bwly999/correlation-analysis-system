# 维护原则

本文档描述整个工作流文档系统的维护规则。

## 同步规则

当以下内容发生变化时，必须同步更新本文档 **根目录下的对应文件**：

### 需要更新本系统文档的变更

- 工作流连接规则、执行顺序或运行目标选择规则
- `NodeResult` 协议、多输入协议或持久化快照模型
- 执行引擎、运行时输入、冻结输出、历史模式
- viewer 注册、预览逻辑、分析弹窗链路
- 结果看板的默认选中规则、布局模式或自动打开行为
- 帮助中心入口、节点帮助展示方式或固定上手流程
- 构建切包与懒加载策略
- 算法出口与部署拓扑
- `data-merge` 横向关联模式下移除各来源原始 key 字段，只保留 `unifiedKeyName` 对应的一列作为合并后的主键字段

### 需要更新 `../工作流节点说明.md` 的变更

- 节点列表、节点职责、节点类别
- `NodeDefinition` / `NodeProperty` 设计
- 新节点创建规则、实现规范
