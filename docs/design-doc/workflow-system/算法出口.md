# 算法出口

本文档描述前端算法节点的后端调用链路。

## 调用拓扑

```
浏览器 (Vue) → Node API (TS/Node) → Python 算法服务
```

浏览器只配置 Node API 地址（`VITE_API_BASE_URL`），Python 地址通过 Node 环境变量注入。

## 路由映射

| 前端请求 (Node API) | Python 后端目标 |
|---------------------|----------------|
| `POST /api/analysis/multiple-linear-regression` | `/analyze/multiple-linear-regression` |
| `POST /api/analysis/random-forest-feature-importance` | `/analyze/random-forest-feature-importance` |
| `POST /api/analysis/logistic-regression-classification` | `/analyze/logistic-regression-classification` |
| `POST /api/analysis/lasso` | `/analyze/lasso` |
| `POST /api/analysis/xgboost-shap` | `/analyze/xgboost-shap` |

## 环境变量

| 变量 | 用途 | 默认值 |
|------|------|--------|
| `VITE_API_BASE_URL` | 前端指向 Node API 的地址 | — |
| `PYTHON_ANALYSIS_API_BASE_URL` | Node 指向 Python 服务的地址 | `http://127.0.0.1:8000` |

## 推荐部署拓扑

```
浏览器 → Node → Python
```
