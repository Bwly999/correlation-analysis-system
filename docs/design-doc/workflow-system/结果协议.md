# 标准结果协议：NodeResult

本文档描述节点输出的标准化结果协议 `NodeResult`。定义位于 `src/nodes/result.ts`。

所有节点的 `execute()` 输出必须经过 `normalizeNodeResult()` 标准化，遵守本协议。

## 基本结构

```ts
export interface NodeResult<T = unknown> {
  kind: DataKind
  payload: T
  schema?: NodeSchema
  meta?: Record<string, unknown>
  preview?: NodePreviewSpec
  lineage?: Record<string, unknown>
}
```

| 字段 | 说明 |
|------|------|
| `kind` | 数据类型标识 |
| `payload` | 实际数据 |
| `schema` | 字段元信息（name, type） |
| `meta` | 元数据（如 `rowCount`） |
| `preview` | 预览配置（指定 viewer 组件 + 图表默认值） |
| `lineage` | 溯源信息 |

## 结果类型（DataKind）

### 当前主用类型

| 类型 | 说明 |
|------|------|
| `table` | 表格数据 |
| `tableCollection` | 分组表格集合 |
| `report` | 分析报告 |
| `chart` | ECharts 图表配置 |
| `file` | 文件导出 |
| `json` | 原始 JSON 数据 |

### 预留类型

`scalar`、`matrix`、`timeseries`、`custom`

## 结果标准化

`normalizeNodeResult()` 自动补齐：

- `table` 的 `schema`（字段名和类型推断）
- `table` 的 `meta.rowCount`
- 缺失时的默认 `preview.viewer`

### Preview 约定

- `preview.props.chartDefaults` 可为 `table` / `tableCollection` 声明首开图表提示：
  - `mode` — 图表模式（折线、散点、柱状等）
  - `xField` — X 轴字段
  - `yFields` — Y 轴字段列表
  - `groupMode` — 分组模式
- 结果预览中的 `DataChart.vue` 首开优先级：
  1. 本地用户设置
  2. `preview.props.chartDefaults`
  3. 内置启发式默认

## 常用创建 Helper

| 函数 | 作用 |
|------|------|
| `createTableResult()` | 创建表格结果 |
| `createTableCollectionResult()` | 创建分组表格集合 |
| `createReportResult()` | 创建报告结果 |
| `createChartResult()` | 创建图表结果 |
| `createFileResult()` | 创建文件结果 |
| `createJsonResult()` | 创建 JSON 结果 |

## Report 结果的 Sections Help

`report` 结果的 `sections[]` 可选声明 `help`：

| 字段 | 用途 |
|------|------|
| `summary` | 一句话说明该输出回答什么问题 |
| `howToRead` | 优先看哪些指标、排序、颜色或趋势 |
| `cautions` | 适用边界、常见误读提示 |

`report-viewer` 把 `help` 渲染为标题旁的说明图标与 tooltip。
