# 工作流模板画廊 UI 调整说明

## 目标

将工作流管理中心中的“分析模板”从普通列表卡，调整为用户一眼能看出重点的结果导向卡片。

## 设计方向

本次采用“结果海报式”：

- 顶部先强调“你会先看到什么分析结果”
- 中部用大标题突出模板最核心的产出
- 用 3 个高权重结果标签强化差异
- 底部再补适合场景、核心节点和下一步建议

## 关键信息层级

1. 第一眼：结果标题
2. 第二眼：重点产出标签
3. 第三眼：适合场景与核心节点
4. 最后：立即生成按钮

## 视觉策略

- 保持现有“极简现代 SaaS”基调
- 用 `Slate-900` 作为整体骨架色
- 每个模板使用不同但克制的强调色区分类型
- 通过渐变、浅色氛围层和圆角面板增强记忆点
- 避免把所有模板做成同一种白底信息卡

## 预期效果

- 新用户不用先理解流程，也能按结果目标选择模板
- 四个模板在第一屏就能明显区分
- 模板区更像“分析成果菜单”，而不是普通功能列表
