核心能力

达成什么效果

相关性分析
Pearson / Spearman / Kendall 三大相关系数，热力图矩阵与因子排名
回归分析
多元线性回归、Lasso 正则化、逻辑回归，含模型评估与残差诊断
机器学习
XGBoost + SHAP 可解释性分析、随机森林特征重要性排序
统计检验
VIF 共线性检测、PCA 降维、方差分析（ANOVA）、分类因子筛选

总结

平台核心价值

  • 低门槛　— 可视化拖拽编排，无需编程基础即可完成专业分析
  • 全链路　— 数据导入、清洗、分析、可视化一站式闭环
  • 可解释　— SHAP / 特征重要性等多维度解读分析结果
  • AI 增强　— MCP 协议接入大模型，自然语言驱动分析流程
  • 可扩展　— 声明式节点体系，新分析算法可快速接入
