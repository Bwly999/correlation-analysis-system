评测人操作流程

  1. 选中左侧题目，复制 Prompt。
  2. 把 `data/` 目录下的 3 个 CSV 发给 Agent，必要时再补 `data/field_dictionary.json`。
  3. 不要把 `data/dataset_truth.json`、参考结论和评分标准提前给 Agent。
  4. 等待 Agent 输出中文结论、关键图表、证据字段和不确定性说明。
  5. 依据右侧评分维度和本题参考结论做人工判断。

评审提醒

`reference_conclusions` 是参考命中点，不是唯一标准答案。重点看它有没有抓住主因、有没有做对跨表关联、有没有把伪相关误判成根因。

如果 Agent 把 `near_match_code` 这类近似键当成稳定主键，或者只报工站/班次相关而没有控制变量，应该明显扣分。
