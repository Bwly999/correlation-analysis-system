# 手机尺寸评测人工评分规则

这套评测专门用于 `Codex`、`Claude Code`、`OpenCode` 等通用 Agent。

评测方式很简单：

1. 评测人选择一个 `tasks/*.json`
2. 用其中的 `prompt` 驱动 Agent 对数据集进行分析
3. 人工查看 Agent 的最终输出
4. 按下面 4 个维度打分

## 评分维度

每项 1-5 分，总分 20 分。

### 1. 结论正确性

- `5`：核心结论基本命中，主因/伪相关判断准确
- `3`：结论部分命中，但主次关系不够稳定
- `1`：主要结论错误，或明显把伪相关当根因

### 2. 证据充分性

- `5`：能引用字段、关联关系、图表或统计结果支撑结论
- `3`：有部分证据，但链路不完整
- `1`：几乎只有主观描述，没有有效支撑

### 3. 图表与结果可读性

- `5`：图表选择合理，标题/解释清楚，业务人员能快速看懂
- `3`：有图表，但解释一般或图表不够贴题
- `1`：没有图表，或图表无法支撑结论

### 4. 表达清晰度

- `5`：中文结论清楚，结构清晰，能明确区分主因、中介、伪相关
- `3`：整体可读，但逻辑层次一般
- `1`：表述混乱，难以判断它到底发现了什么

## 评审提醒

- `reference_conclusions` 是参考命中点，不是唯一标准答案
- 优先看结论是否靠谱、是否有证据，不要求措辞逐字一致
- 如果 Agent 使用了错误 join 或把近似键当稳定主键，应明显扣分
